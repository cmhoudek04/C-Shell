# What Is This?
This was an educational project focused on learning how to write a UNIX style shell
(terminal) in C. The project was done following [this](https://brennan.io/2015/01/16/write-a-shell-in-c/) 
 tutorial by Stephen Brennan. 

# What Did I Learn?
This was a very fun project. It taught me about how C takes user input from args and
how terminals work under the hood for simple commands like cd as well as tokenizing
user inputs to parse commands.
